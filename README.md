# KT กรอบพระไทยแลนด์ · ดราฟต์หน้าแรก

ดราฟต์ HTML สำหรับให้ลูกค้าเลือกแบบ ก่อนขึ้นเว็บจริงบน WordPress

- `site/` ไฟล์ที่ deploy (Vercel output directory)
  - `index.html` หน้าเลือกแบบ
  - `v1-showcase/` ตู้โชว์ร้านทอง (แนะนำ)
  - `v2-heritage/` ช่างหลวง
  - `v3-modern/` จิวเวลรีสมัยใหม่
- `build/` สคริปต์สร้างหน้า (`python3 build/make.py`)
- `REQUIREMENTS.md`, `DESIGN.md`
